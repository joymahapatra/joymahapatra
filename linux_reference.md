* **Common Unix shells:** `bash` (Bourne Again Shell), `sh` (Bourne Shell), and `csh` (C Shell).

* **`.tar` files:** **tarball**.

```sh
tar -xvf archive.tar
tar -xvzf archive.tar.gz
```

## Common usages

* `tldr` — simplified command help.

* `env`, `printenv` — view or modify environment variables.

* `uname` — display system information.

* `export PATH=$PATH:/new/path` — update `PATH` (or add it to `~/.bashrc`).

* `passwd` / `yppasswd` — change local / NIS password.

* `su <user>` / `sudo <command>` — switch user / run a command as another user.

* `who` / `whoami` — logged-in users / current user.

* `which`, `whereis`, `type` — locate or identify commands.

* `kill`, `killall` — terminate processes.

* `ps`, `top` — view running processes.

* `ls -l` — view file permissions (`owner`, `group`, `others`).

* `chmod`, `chown` — change permissions and ownership.

* `echo $VAR` — print a variable.

* `sort`, `grep`, `wc`, `cat` — text processing utilities.

* `find . -name "*.txt"` — search for files.

* `touch` — create an empty file.

* `open <file>` — open a file with the default application.

* `mv`, `cp`, `rm`, `pwd` — move, copy, remove files, and print the working directory.

* `gzip`, `tar` — compress and archive files.

* `diff` — compare files or directories.

* `alias ll='ls -al'` — create a command shortcut.


## Storage Management

* `free -h` — display memory usage.

* `lsblk` — list block devices and partitions.

* `df -h` — show mounted filesystems and disk usage.

* `du -sh <path>` — display the size of a file or directory.

* `blkid` — show filesystem UUIDs and types.

* `mount`, `umount` — mount or unmount a filesystem.

* `/etc/fstab` — configure filesystems to mount automatically at boot.

* `fsck <device>` — check and repair a filesystem *(run on an unmounted filesystem)*.


## User Management

* `sudo useradd -m -d <HOME_DIR> -s /bin/bash <USERNAME>` — Create a user (You don't have to create home directory beforehand).

* `sudo passwd <USERNAME>` — Set or change a user's password.

* `sudo usermod -d <HOME_DIR> <USERNAME>` — Change the home directory.

* `sudo usermod -s /bin/bash <USERNAME>` — Change the login shell.

* `sudo userdel -r <USERNAME>` — Delete a user and their home directory.

* `sudo adduser <USERNAME> sudo` — Grant sudo privileges.

* `setfacl -m u:<USERNAME>:rwx <DIRECTORY>` — Grant access to a directory.

##  Building Software from Source (GNU Autotools)

* `./configure` — Check dependencies, configure the build, and generate `Makefile`.

* `make` — Compile the source code using the generated `Makefile`.

* `sudo make install` — Install the compiled files into the target system (typically `/usr/local`).

* `configure` and `Makefile.in` are generated by the **GNU Autotools** (`autoconf` and `automake`).

* See also: [link](https://thoughtbot.com/blog/the-magic-behind-configure-make-make-install).

## GNU screen

```sh
screen -S session_name
screen -ls
# Detach a session: `ctrl+ a` and `ctrl+ d`
screen -r session_name # attach a screen session
screen -d -r session_name # force reattach
```

## SSH Configuration: Add the following entries to `~/.ssh/config`

```sshconfig
# SSH configuration file

Host Name1
    HostName <IP_ADDRESS>
    User <USERNAME>
    Port <PORT>
    PasswordAuthentication yes

Host Name2
    HostName <IP_ADDRESS>
    User <USERNAME>
    Port <PORT>
    PasswordAuthentication yes
    ProxyJump Name1
```

## Passwordless SSH and file/directory transfer

```sh
ssh-keygen
ssh-copy-id -i ~/.ssh/id_rsa.pub <USER>@<HOST>
vim ~/.ssh/authorized_keys # view authorized public keys
scp -r <SOURCE> <USER>@<HOST>:<DEST> # securely copy files (-r: recursive).
rsync -ravz <SOURCE> <USER>@<HOST>:<DEST> # synchronize files (-r: recursive, -a: archive, -v: verbose, -z: compress during transfer).
```

### Markdown to PDF

Use `pandoc` to convert Markdown files to PDF.

```sh
sudo apt install pandoc
pandoc --from=gfm --to=pdf -o README.pdf README.md
pandoc README.md -o README.pdf
```
